# Code of conduct

## The short version

Be decent. Argue with the work, not the person. Assume the other reader is competent and acting in
good faith until they prove otherwise.

## What is not acceptable

Harassment, personal attacks, discriminatory language, sexualised language or imagery, publishing
anyone's private information, and sustained disruption of a discussion. Whether it was meant as a
joke does not change how it lands.

## Scope

This applies to issues, pull requests, discussions, and commit messages in this repository, and to
anywhere someone is representing the project.

## Enforcement

Report it through GitHub's [private vulnerability reporting](https://github.com/matt-pasek/usva/security/advisories/new)
form, which is the only private channel this repository has. Reports stay confidential.

usva. is maintained by one person, so enforcement is not a committee. I will read it, and the response
is a warning, a deleted comment, or a block, depending on what happened. Repeated or severe behaviour
skips straight to the block.
